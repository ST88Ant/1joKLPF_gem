### ⚠ `지출_총금액` 해석 주의 (검증 결과)

거주자 지출이 **아니라 소비지(상권) 기준**이다. 실측 상관계수:

- 지출총액 ~ 상주인구: **r = −0.014** (2021Q1~2026Q1 전 분기 −0.01~−0.03로 일정)
- log(지출총액) ~ log(집객시설수): **r = +0.685**

소공동 한 동이 서울 전체 지출의 17.6%(2.29조원/분기)를 차지한다. 서울 합계는 9.03조(2021Q1) → 13.6조(2026Q1)로 매끄럽게 증가해 **총량은 정상**이나, 동별 배분은 상권 규모를 따른다.
→ **"거주자 소비성향" 분모로 쓰면 안 된다.** 상권 활력 보조지표로만 사용할 것.
→ 거주자 소비 대리지표는 아래 SKT 데이터의 `소액결재 사용금액 평균`을 쓴다.

참고: `월_평균_소득_금액` 컬럼은 2026-05-13자로 **삭제**됨(2020년부터 수급 중단). `소득_구간_코드`도 2026-06-25 삭제 예정. 상권/상권배후지 버전(OA-21278, OA-15571)도 동일하게 삭제 확인.

## 데이터 품질 이슈 3건 (반드시 읽을 것)

### ① `지출_총금액`은 거주자 소비가 아니다 — 소비지(상권) 기준
- 지출총액 ~ 상주인구 **r = −0.014** (2021Q1~2026Q1 전 분기 −0.01~−0.03)
- log(지출총액) ~ log(집객시설수) **r = +0.685**
- 소공동 1개 동이 서울 전체의 17.6%(2.29조원/분기). 서울 합계는 9.03조→13.6조로 정상 증가.
- → 거주자 소비 대리지표는 **SKT `소액결재 사용금액 평균`**(야간상주지=거주지 기준)을 쓴다.

### ② SKT `요금 연체 비율`에 2배 레벨 시프트가 있다
2023년 월별 원자료 평균: 1월 6.64 / 2월 14.26 / 3월 13.47 / 4월 13.11 / 5월 6.66 …
9~11월 13.6~14.4 / 12월 6.79. 2025.03도 19.67로 동일 현상. 정의·분모 변경으로 추정.

동별 순위는 레짐이 바뀌어도 보존된다:
- 동일 레짐 (2023.01 vs 05): Spearman ρ = **0.984**
- 레짐 교차 (2023.01 vs 02): Spearman ρ = **0.886**, 배율 중앙값 2.22

→ **분기 내 Z-score로 표준화하면 완전히 상쇄된다.** 절대수준 시계열 비교는 금지.

### ③ 상권분석 상주인구·가구수가 재건축 지역에서 낡았다

| 둔촌1동 | 16 | 22,127 |

전체 상관 r=0.941이나 꼬리가 망가져 **비율의 분모로 쓸 수 없다**. 모든 인구·가구 비율의 분모는 `SKT_총인구`를 쓴다. `인구갱신괴리`(=상권분석인구/SKT인구) 컬럼으로 해당 동을 식별할 수 있다.
